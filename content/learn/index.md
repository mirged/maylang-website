# Learn Maylang

Maylang is small enough to learn in an afternoon and strict enough to keep the program honest after that. Start with a running project, then follow the tour one concept at a time.

## First steps

- [Get started](/learn/get-started/) — install, create a workspace, run it, test it and format it.
- [Install Maylang](/install/) — the installer, unattended setup, WSL 2, offline bundles, updates and uninstalling.
- [Take the tour](/learn/tour/) — one runnable sample per concept.

## Guides

- [Strict typing](/learn/strict/) — how checking works, what the compiler infers, and where `Any` belongs.
- [Networking](/learn/network/) — TCP and UDP with `stdlib/net`.
- [Cookbook](/learn/cookbook/) — short recipes for common tasks.

## Before you start

Maylang currently supports **Linux x86-64**, including x86-64 **WSL 2**. The language is experimental: expect breaking changes and check the [roadmap](/roadmap/) before relying on it for anything important.
