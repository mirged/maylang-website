Install in one line

On Linux x86-64 or WSL 2, run:

sh
curl --proto '=https' --tlsv1.2 -fsSL https://github.com/mirged/maylang/releases/latest/download/maylang-init.sh | sh

Then create and run a project:

sh
may new hello
cd hello
may run

No checkout, Rust, Python, C compiler or build command is needed for the default install. Installation options cover unattended setup, WSL, offline bundles, updates and uninstalling.

Three ideas, one toolchain

Strict by default

Signatures are typed, collections say what they hold, and match must cover every case. Recoverable failures use may { … } otherwise { … }, and dynamic code crosses an explicit Any boundary.

Read the strict typing guide

Self-hosted

The compiler, formatter, language server and workspace runner are written in Maylang. A Rust → C bootstrap rebuilds the compiler from source until stage 2 and stage 3 agree byte for byte.

How the bootstrap works

Its own backend

mayc lowers Maylang to x86-64 and emits ELF itself. There is no LLVM dependency, no external assembler and no linker in the normal compile path.

What is in the language

Small, complete examples. Samples in the guides and tour are compiled and run against the released compiler before the site ships.

Errors

Recoverable faults

may and otherwise catch I/O, arithmetic, parsing and explicit fail calls without a separate exception type.

 Concurrency

Closures and fibers

Functions are values, closures capture shared bindings, and spawn schedules cooperative fibers in the same process.

 Data

Structs and enums

Named records and tagged variants, with exhaustive match and typed payloads.

 Text

A Unicode-correct string model

Strings are UTF-8. len and indexing count code points; byte operations are explicit when working with networks or files.

 Network

TCP and UDP in the library

Synchronous IPv4 sockets in stdlib/net, with structured network errors.

 Desktop

A native UI library

Widget trees, layout, text input and GPU drawing through the optional Sokol adapter.
